# NOTES — konceptové poznámky

Jedna poznámka na koncept, **psaná studentem vlastními slovy** (5–10 řádků).
Claude Code je jen čte a opravuje chybné intuice — nepíše je.

Název souboru = koncept, např. `class-imbalance.md`, `data-leakage.md`,
`precision-recall.md`. Dobrá poznámka odpoví na tři otázky:

1. Co to je (jednou větou, bez vzorce).
2. Kde se to projevilo na *našich* datech (konkrétní pár, číslo, kniha).
3. Kdy to selže / na co si dát pozor.
